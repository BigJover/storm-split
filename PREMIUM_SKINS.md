## The idea in one paragraph

Today's skins (Swamp Stalker → Gold Rush) are the **basic line**: earned by level or bought with
Amber, in normal colours, no glow. The **premium line** is a step up you can see from across the
map: every premium theme has **one signature effect** — glowing seams that breathe, sparks or
dust drifting off the hunter, coloured tracers, coloured grenade blasts, a recoloured ability.
Each theme dresses **all four hunters, all four guns, all 18 towers, all four grenades and all
four abilities** in one look, so a player can go "full Lava Lord". Cosmetic only: nothing changes
damage, range, hitboxes or how readable a fight is.

## What makes premium different from basic

| | Basic (today) | Premium (new) |
|---|---|---|
| How you get it | Player level or Amber (Robux bundles are a shortcut) | **Robux** (recommended: Robux only, see question 2) |
| Hunter | New outfit pieces, normal colours | New outfit **+ glowing parts that breathe or shift colour + a small particle aura** |
| Gun | New pieces, recolour | New pieces **+ glowing parts + its own tracer colour** |
| Towers | Trim + one themed piece per tower | Trim + piece **with glow that animates; sparks/dust at stage 2 (tier 5)** |
| Grenade | — (none today) | Recoloured / reshaped grenade **+ explosion colour** |
| Ability | — (none today) | **Ability colour + a small particle swap** (no new models) |
| Covers | One hero (or towers) per item | A whole theme across every slot |

## Prices (Robux) — Jovan's call, this is the recommendation

The Store today: Amber packs R$49 / 199 / 799, passes R$199–299, and the basic **bundles R$249–599**
(set + hunter + gun; Gold Rush is the top at R$599). Premium must sit clearly above that, and Roblox
games of this kind sell single skins for about R$100–400 and full bundles for R$1,000–2,000.

| What you buy | Contents | Price | Why |
|---|---|---|---|
| Hunter skin | 1 premium hunter | **R$249** | Equal to a whole basic bundle: the "this one is special" signal |
| Weapon skin | 1 premium gun (with its tracer colour) | **R$149** | Guns are seen most (first person), but smaller models |
| Tower set | Trim + all 18 tower pieces | **R$349** | Biggest single item: 19 models, shows on every tower you place |
| **Class Pack** | Hunter + gun + grenade + ability for one class | **R$449** | The everyday buy. Grenade and ability skins come **only** in packs |
| **Theme Bundle** | All 17 items of a theme | **R$1,499** | Singles would be R$1,941 *without* the 8 pack-only items: the whale buy, saves about a quarter |

Why grenades and abilities are pack-only: they're the "less detailed" pieces, and selling them
one by one would mean 8 more products per theme (each needs its own id on Creator Hub). Packs keep
the Store to **14 products per theme** (4 hunters, 4 guns, 1 set, 4 packs, 1 bundle).

**Limited or rotating?** Recommendation: **no limited items at launch — everything stays for sale.**
The Store's wording rules (Round 22) already forbid countdown pressure, and a first game shouldn't
lean on fear-of-missing-out. Instead:
- a **"Featured" theme** at the top of the Skins tab, changed every week or two (just the order,
  no timer);
- **seasonal themes** (Phantom Hunt in October) that are only sold in their season and return
  every year, said plainly ("back every October"), never as a ticking clock.

Already-owned items: the bundle card already lists what you own (#412). Roblox prices can't drop
per player, so a player who bought two Class Packs pays full price for the bundle. Fine for launch;
a "Complete the theme" product could come later if players ask.

## Rules that stay (readability and fairness)

Premium is **cosmetic only** (#389: nothing Robux-only changes combat). Every premium item keeps:
- the **same hitbox envelope** as the class body (#434) and the same gun grip/muzzle (#453);
- **no see-through parts**, name tag and outline untouched (#381);
- tower silhouette inside the 3×5×3 box, flag and Rescue Beacon corners clear, muzzle lane clear,
  crown marker and HP bar untouched (#447, #457);
- **ability skins change colour and particles only** — never the radius, shape, timing, sound or
  the warning ring. A recoloured Flare Strike still shows its warning; a recoloured Triage Kit
  still reads as a heal (and never uses a red cross: protected emblem);
- **tracer / blast colours can't copy game signals** — not the dino-throw warning colour, not a
  camp colour in battles (checked when the theme colours are written);
- a glowing hunter is easier to see, not harder, so glow gives no hiding advantage. Auras are kept
  small and low so they never cover another player's name tag;
- **mastery 20 gold still shows** on a premium gun: as today, steel and brass go gold and the skin
  keeps its own pieces (#453).

## Production plan

### Budgets (same as the approved art pass, #433)

| Model | Budget | Notes |
|---|---|---|
| Hunter body variant | ≤ 6,000 tris | Built like 11e: the approved class body with pieces dropped/added |
| Gun variant | ≤ 1,200 minus that gun's attachments | Pistol 880, Rifle 864, Shotgun 868, Carbine 1,200 (as 11e) |
| Tower set trim | ≤ 300 | Same checks as `_sets.py` |
| Tower set piece | ≤ 800–1,000 | Same `setpiece()` checks as 11e2 (box, corners, muzzle lane, Tar Pit ≤ 0.8) |
| Grenade variant | ≤ 600 | Base grenades are 328–560 |
| Ability | 0 | Effects only |

One theme ≈ 48,000 tris of models, but a player only ever sees one hunter + one gun at a time, and
towers are already budgeted per tower.

### What reuses what's already built (no new runtime)

| Piece | Reuses |
|---|---|
| Hunter skins | `HunterBody` wearing `hunter/<SKIN KEY>` (#446, #456), exactly like Gold Rush Safari |
| Gun skins | `GunArt` wearing `gun/<HERO>_<SKIN KEY>`, both hands for Dual Pistols, attachments on top |
| Tower sets | `TowerLook` trim `tower/SET_<SET>` + pieces `tower/SET_<SET>_<TOWER>` (#458) |
| Glowing parts | the art's `glow` paint group is already Neon in game (#439) |
| Buying | the Store's existing `skins` grant (a single item is a product with one key in `items`); receipts, ledger and "never lose a purchase" unchanged |
| Owning / wearing | `Shared/Skins` owned + wear map; the saved shape doesn't change |

### What's new (kept small, visual only)

| New piece | Where it runs | Size |
|---|---|---|
| **Theme effects table** (`Shared/PremiumFx`, pure + spec'd): per theme its tracer colour, blast colours, ability colours, particle preset, glow animation (Pulse or Cycle) | shared | small: one table + lookups. Visual values may live in code (DIRECTION) |
| **Animated glow**: a premium model's `glow` pieces breathe or shift colour, reusing `Cosmetics.animatedColour` (the animated gun sets already do this) | **client only** (`Looks.client`) | small |
| **Particle auras**: one small emitter on the hunter, one at a stage-2 tower's top, a faint one at the muzzle; created on each client, never by the server | **client only** | small–medium: needs caps (below) |
| **Tracer + blast colours**: the server already draws tracers and blasts with a colour; it just asks `PremiumFx` for the worn skin's colour instead of the hero's | server, colour only | tiny |
| **Ability recolour + a particle burst**: the ability's rings/marks take the ability skin's colours; the extra sparkle is spawned client-side | server colour + client burst | small |
| **Two new skin kinds**, `grenade` and `ability` (slots `grenade:<HERO>`, `ability:<HERO>`), worn from the same Wardrobe | shared + Wardrobe UI | small |
| **Grenade art hookup**: `kit/<HERO>_GRENADE_<SKIN KEY>` when loaded, else the base grenade | shared | small |
| **"Robux only" shop line**: a premium row says "In the Store — R$249" instead of "Not for sale yet" | shared + UI | tiny |
| **Spreadsheet**: Skins sheet gets `tier` (basic / premium) and `theme` columns + the new rows; Store sheet gets the 14 products per theme (ids blank until publishing) | sheet + exporter checks | data |

Performance caps (client): at most ~20 premium tower emitters active (nearest first), hunter auras
≤ 4 particles a second, everything off in the hunter's own first-person view and dropped first on
low graphics settings. Nothing new replicates from the server except a colour.
Pack tier (#464, v3 #465): one hunter's whole pack layer <= 30 particles a second; pooled world pieces
(marks 16, drips 6, ground rings 6, tracer bolts 8, take-down sets 3, grenade splashes 4); rates scale
with graphics quality; within 120 studs only.
